# AirPaste website

Static site served at https://airpaste.co.uk by GitHub Pages.

- `index.html` is the home page; `download.html`, `why.html`, `what.html`, `whatsnext.html` and `shop.html` are the other pages.
- `CNAME` holds the custom domain. Don't delete it.
- Pushing changes under `website/` to `main` deploys automatically via `.github/workflows/pages.yml`.
- To preview locally, serve this folder (e.g. `npx serve website`) and open the printed URL.
