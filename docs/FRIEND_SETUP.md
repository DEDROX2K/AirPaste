# Getting started with AirPaste

AirPaste keeps your boards as plain files in a folder. We sync that folder with Google Drive, so we both see the same boards.

## 1. Install AirPaste
1. Download **AirPaste Setup 1.0.0-beta.1.exe** (the link I sent you).
2. Double-click it and follow the installer.
3. If Windows shows a blue "Windows protected your PC" screen, click **More info → Run anyway**. The app isn't code-signed yet, so this is expected.

## 2. Install Google Drive for desktop
1. Download it from https://www.google.com/drive/download/ and install it.
2. Sign in with the Google account I gave you.
3. Wait until Drive finishes its first sync. You'll see a **Google Drive** (G:) drive in File Explorer.

## 3. Make the AirPaste folder available offline
1. In File Explorer, open **G: → My Drive → AirPaste** (the folder I'll name for you).
2. Right-click the folder → **Offline access → Available offline**.

This makes the files really live on your computer, so AirPaste can read them quickly.

## 4. Open it in AirPaste
1. Launch AirPaste.
2. Click **Open folder** and pick that same **AirPaste** folder in your Google Drive.
3. Your boards show up. Done!

## Tips
- **Don't edit the same board at the same time as me.** Drive can't merge changes, so one of us would overwrite the other. Quick check: if the Drive icon in your taskbar says "Syncing", wait for it to finish before closing the app.
- **Closing the app:** let Drive finish syncing before you shut down your PC.
- **Something looks missing?** Check the Drive tray icon is signed in and not paused.
- Any problem: message me.
